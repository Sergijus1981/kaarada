# KaaRada Lite

🛡️ Trust Layer bot for Kenya. Check phone numbers, Till numbers, and businesses before sending money.

## Features

- Phone number verification
- Till/Paybill validation
- Business reputation check
- User reports
- English + Kiswahili

## Deploy

Set environment variables:
- `KAARADA_BOT_TOKEN` — Telegram bot token
- `KAARADA_OWNER_ID` — your Telegram user ID

Start: `python kaarada_bot.py`
